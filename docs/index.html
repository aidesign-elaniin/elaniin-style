Elige tu camino

¿Quién va a instalarlo?

Equipo: se instala desde la app de Claude, sin terminal. Dev: CLI, scopes, auto-update y edición de piezas.

Para el equipo

Instálalo en 5 pasos, sin terminal

Todo ocurre dentro de Claude. Toma menos de dos minutos y solo se hace una vez.

  1. 01

    Abre Claude y entra a Plugins

    En la app de Claude (o en claude.ai) abre el menú Customize y luego Plugins.

  2. 02

    Agrega el marketplace de Elaniin

    Pulsa Add → Add marketplace y pega esta dirección. Si Claude pide conectar GitHub, acepta: es solo para leer el plugin.

    dirección 
    aidesign-elaniin/elaniin-style

  3. 03

    Instala Elaniin Style

    Entra a Discover, elige elaniin-style y pulsa Add. Queda guardado en tu cuenta.

  4. 04

    Actívalo la primera vez

    Escribe / en el chat y elige elaniin-style. Después Claude lo usa solo cuando pides algo Elaniin.

  5. 05

    Deja que se actualice solo

    En la entrada del marketplace activa Sync automatically. Así recibes las mejoras sin hacer nada más.

Preguntas frecuentes

¿Tengo que instalar algo en mi computadora?+

No. Se instala dentro de Claude, desde la pantalla de Plugins. No usas terminal.

¿Cómo sé que está activo?+

Pídele a Claude un deck o una página “con el estilo Elaniin”. Debe usar el logo oficial, blanco y gris con bandas azul oscuro, y animaciones suaves.

¿Cuándo llegan las mejoras?+

Si activaste Sync automatically, solas. Si no, abre Plugins y pulsa Check for updates.

Mi deck o página necesita un cambio fino+

Pídeselo a Claude en la misma conversación. Si necesitas edición manual, pasa el archivo HTML a una persona de desarrollo: está hecho con Tailwind para eso.

No encuentro el marketplace o me pide permisos+

Pide a tu líder de equipo que te dé acceso al repositorio de GitHub de Elaniin Style y vuelve a intentar el paso 02.

01

Instalar con la CLI

Requiere Claude Code. El plugin vive en el marketplace elaniin-style-marketplace de este repositorio.

bash 
# 1) agregar el marketplace
claude plugin marketplace add aidesign-elaniin/elaniin-style

# 2) instalar (scope user por defecto)
claude plugin install elaniin-style@elaniin-style-marketplace

# 3) verificar
claude plugin list

Todo en un paso (Claude Code 2.1.292 o superior):

bash 
claude plugin install elaniin-style --marketplace aidesign-elaniin/elaniin-style

Dentro de una sesión de Claude Code, los mismos pasos son:

claude code 
/plugin marketplace add aidesign-elaniin/elaniin-style
/plugin install elaniin-style@elaniin-style-marketplace
/reload-plugins

02

Elegir el scope

Agrega --scope al comando install. Local gana sobre proyecto, y proyecto sobre usuario.

user

~/.claude/settings.json

Predeterminado. Para todos tus proyectos.

project

.claude/settings.json

Se commitea. Cada colaborador corre una vez el install.

local

.claude/settings.local.json

Solo tú, solo este repo.

03

Habilitarlo en un repo compartido

Commitea esto en .claude/settings.json para que todo el equipo vea el marketplace. Se aplica después de aceptar la confianza del folder, y cada persona aún corre claude plugin install … --scope project una vez.

json 
{
  "extraKnownMarketplaces": {
    "elaniin-style-marketplace": {
      "source": { "source": "github", "repo": "aidesign-elaniin/elaniin-style" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": {
    "elaniin-style@elaniin-style-marketplace": true
  }
}

04

Repositorio privado

Claude Code corre git sin prompts, con tus credenciales existentes. No hay campo de token en el marketplace.

bash 
# HTTPS
gh auth login
gh auth setup-git

# o SSH: llave en ssh-agent sin passphrase y github.com en known_hosts
# fuerza HTTPS si no quieres que pruebe SSH primero:
export CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1

La actualización en segundo plano solo usa credenciales guardadas: GITHUB_TOKEN por sí solo no la autentica.

05

Actualizar y desinstalar

El plugin no define version: cada commit del repo cuenta como versión nueva. Con autoUpdate activo se descarga solo unos minutos después de abrir una sesión; la sesión en curso conserva la versión cargada hasta /reload-plugins o reiniciar.

bash 
# actualizar a mano
claude plugin update elaniin-style@elaniin-style-marketplace
# o desde una sesión
/plugin marketplace update elaniin-style-marketplace
/reload-plugins

# desinstalar / quitar el marketplace
claude plugin uninstall elaniin-style@elaniin-style-marketplace
claude plugin marketplace remove elaniin-style-marketplace

06

Usar el skill

Claude lo carga solo cuando el pedido encaja. También puedes invocarlo con su nombre con namespace:

claude code 
/elaniin-style:elaniin-style

Cuatro modos: deck, dashboard, website y site-dev (el sitio Elaniin 2027 en Next.js). Pide en español o inglés; el skill responde en tu idioma. El script que instala motion corre en silencio solo si el proyecto tiene package.json.

07

Editar un deck o una página generada

Los entregables son un solo archivo HTML autocontenido: llevan Tailwind v4 (@tailwindcss/browser fijado en 4.3.3) y el bloque de tokens embebido. No dependen de que el plugin siga instalado ni se actualizan solos: son del proyecto. Se editan con clases de Tailwind como cualquier HTML.

Color

bg-elevate-blue · bg-excellence-blue · bg-inspire-grey · text-text-primary · text-text-secondary · text-text-muted

elevate-blue solo como detalle (<5% del área).

Tipografía

font-display · font-text · font-mono · text-display-xl · text-h1…h4 · text-lead · text-body · text-caption

Escala fluida; no uses tamaños sueltos.

Forma y sombra

rounded-button · rounded-card · rounded-input · shadow-card-rest · shadow-menu · shadow-product

Radios y sombras vienen de @theme.

Layout

container-site · section-y · section-y-statement · section-y-compact · pad-card

Gutter y ritmo vertical responsive.

Movimiento

duration-fast · duration-base · duration-slow · duration-reveal · rise · reveal · card-glow · lift · btn-arrow

Duraciones con nombre: nunca duration-200.

Foco

focus-ring · focus-ring-on-dark

Anillo doble visible en :focus-visible.

Breakpoints

sm 640 · md 768 · lg 1024 · xl 1280

Los defaults de Tailwind se resetean a propósito.

Reglas al editar

  • Sin hex ni valores sueltos: usa el token (bg-elevate-blue, no bg-[#1054ff]).
  • Colores y escalas por defecto de Tailwind no existen: bg-red-500 no compila.
  • Nada de selectores de clase sueltos en <style>: cada recurso nuevo es un @utility.
  • El deck no lleva clases responsive: su canvas siempre mide 1280×720. Usa grid-cols-3, no md:grid-cols-3.
  • Mantén min-w-0 en hijos de grid/flex y overflow-hidden en cards: cero overflow.
  • Todo elemento con lift o card-glow es una card: lleva rounded-card border bg-surface-card pad-card. Nunca texto pegado al borde del hover ni márgenes negativos.
  • Respeta reduced-motion: toda animación nueva debe apagarse con prefers-reduced-motion.

Ejemplo

html 
<a class="inline-flex h-12 items-center rounded-button bg-elevate-blue px-6
          font-display font-medium text-white hover:bg-blue-600 active:bg-blue-700
          transition-colors duration-base focus-ring">
  Empezar
</a>

El script de navegador necesita internet para compilar. Para llevar la pieza a un proyecto real, cambia al plugin de build y pega tokens.css (está en skills/elaniin-style/templates/) en tu CSS de entrada.

Vite

bash 
npm install tailwindcss @tailwindcss/vite
ts 
// vite.config.ts
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({ plugins: [tailwindcss()] })
css 
/* src/index.css — @import va PRIMERO */
@import "tailwindcss";

/* …y debajo pega el contenido completo de tokens.css
   (@theme, :root, @utility, @layer base) */

Next.js

bash 
npm install tailwindcss @tailwindcss/postcss postcss
js 
// postcss.config.mjs
const config = { plugins: { "@tailwindcss/postcss": {} } };
export default config;

Inventario completo clase → token → valor: references/tailwind-api.md dentro del plugin.

08

Textura interactiva: module field

Es la textura firma del sitio Elaniin: una cuadrícula de cuadritos de 2 px cada 16 px (gris al 45%) que, al mover el mouse, se enciende celda por celda subiendo la rampa blue-300 → blue-400 → blue-500 y se apaga en ~260 ms. Va en el fondo del hero y del CTA final. Es la misma del sitio elaniin-2027-website-main, portada como recurso del skill.

module-field

Cuadrícula en reposo, solo CSS. Primer hijo del host.

Base obligatoria.

module-field-dark

Cuadritos blancos tenues para bandas oscuras.

Sobre excellence-blue.

module-field-mask-left / -none

Desvanece hacia la izquierda, o sin desvanecer.

Por defecto se desvanece hacia abajo.

--module-size · --module-pitch

2px · 16px en :root. El rastro lo lee del CSS.

Cámbialos solo en tokens.

HTML (el host debe llevar relative isolate overflow-hidden y el contenido relative):

html 
<section class="relative isolate overflow-hidden section-y">
  <div class="module-field" data-module-field aria-hidden="true"></div>
  <div class="container-site relative">…contenido…</div>
</section>

<!-- sobre fondo oscuro, desvanecida a la izquierda -->
<section class="relative isolate overflow-hidden section-y bg-excellence-blue text-white">
  <div class="module-field module-field-dark module-field-mask-left"
       data-module-field aria-hidden="true"></div>
  <div class="container-site relative">…contenido…</div>
</section>

El rastro del mouse es un script de ~90 líneas sin dependencias. Los templates ya lo traen inline; en otros proyectos:

html 
<script src="module-field.js"></script>
<!-- o pega el contenido de templates/module-field.js dentro de un <script> al final del body -->

React / Next.js

tsx 
// Next.js / React: copia templates/module-field.tsx a src/components/
import { ModuleField } from "@/components/module-field";

<section className="relative isolate overflow-hidden section-y">
  <ModuleField />                       {/* fade="bottom" tone="light" */}
  <div className="container-site relative">…</div>
</section>

<ModuleField fade="left" tone="dark" /> {/* para bandas excellence-blue */}

Reglas

  • Solo en hero y CTA final, una por sección. Nunca como relleno de cards ni detrás de bloques de texto largo.
  • Es textura, no protagonista: opacidad en reposo 45% y sin glows ni degradados encima.
  • Los cuadritos son decorativos: aria-hidden="true" y sin eventos de puntero propios.
  • En pantallas táctiles y con prefers-reduced-motion no hay rastro: queda solo la cuadrícula estática.
  • El script también se necesita si agregas la textura a un HTML ya generado: sin él solo verás la cuadrícula en reposo.

09

Despliegue para toda la organización

Para que el auto-update sea obligatorio y nadie pueda apagarlo, ponlo en managed settings (Organization settings → Claude Code → Managed settings, MDM o managed-settings.json). Con autoUpdate definido ahí, el toggle de /plugin queda bloqueado.

json 
{
  "extraKnownMarketplaces": {
    "elaniin-style-marketplace": {
      "source": { "source": "github", "repo": "aidesign-elaniin/elaniin-style" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": {
    "elaniin-style@elaniin-style-marketplace": true
  }
}

Si usan DISABLE_AUTOUPDATER=1, agreguen FORCE_AUTOUPDATE_PLUGINS=1 para mantener las actualizaciones del plugin.

10

Solución de problemas

bash 
claude plugin list              # ¿está instalado y habilitado?
claude plugin details elaniin-style
/status                         # ¿qué settings se aplican?

¿Falla el clone? Revisa las credenciales de git (bloque 04). ¿No aparece el comando? Corre /reload-plugins o abre una sesión nueva. ¿Sigue la versión vieja? claude plugin update y recarga.
