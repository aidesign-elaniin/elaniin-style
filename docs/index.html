Who is installing it?

Not a dev: install from the Claude app, no terminal. Dev: CLI, scopes, auto-update and editing pieces.

Install it in 6 steps, no terminal

Everything happens inside Claude, in the Plugins page. It takes a couple of minutes and you only do it once.

  1. 01Open Customize, then Plugins

    In the Claude desktop app (or at claude.ai) look at the left sidebar and click Customize. Then click Plugins. You must be signed in to your Claude account.

    Shortcut: claude.ai/customize/plugins

  2. 02Choose Add, then Add marketplace

    On the Plugins page click Add, then choose Add marketplace. A box opens asking for the address of a repository.

  3. 03Paste the Elaniin address

    Copy the address below, paste it in the box and confirm. The repository is public, so you do not need your own GitHub account. Use this exact address every time.

    address 
    https://github.com/aidesign-elaniin/elaniin-style

  4. 04Install elaniin-style

    Go to Discover, find elaniin-style and click Add. It is saved to your account, so it is also available in chat, Cowork and Claude Code.

  5. 05Turn on automatic updates

    Back in Plugins, find the Elaniin marketplace you added and turn on Sync automatically. To refresh by hand at any time click Check for updates.

  6. 06Use it

    In any chat type / in the message box, type elaniin and pick elaniin-style, then write what you want, for example “Create a pitch deck in the Elaniin style”. You can also just describe the task: Claude loads the skill when it matches.

How to know it worked

Open Customize → Plugins: elaniin-style is listed and its Disable plugin toggle is on. If you type /elaniin in a chat, the skill shows up in the menu.

Using the Code tab of the desktop app+

A plugin you add from Customize is downloaded to the Code tab the next time you start a session signed in to the same account.

If it is not there yet, type /reload-plugins in the session, or start a new one. You can also click + next to the prompt box and choose Add plugins or Manage plugins.

In the Code tab invoke it by typing /elaniin-style:elaniin-style. Plugins are available in local and SSH sessions, not in cloud sessions.

Do I have to install anything on my computer?+

No. It installs inside Claude, from the Plugins screen. No terminal needed.

I do not see “Add marketplace”+

On company Claude plans an administrator decides whether people can add their own marketplaces. Ask the person who manages your Claude workspace to allow it or to add Elaniin Style for you.

It does not show up when I type /+

Open Customize → Plugins and check that elaniin-style is on. Then start a new conversation. In the Code tab type /reload-plugins or start a new session.

When do improvements arrive?+

On their own if you turned on Sync automatically. If not, open Plugins and click Check for updates.

I get an error saying “network source differs”+

You had already added Elaniin Style with a different form of address. In Plugins open the Elaniin marketplace, click Remove, and add it again pasting the full address from step 03.

Claude asks me to connect GitHub+

The Elaniin repository is public, so this is not normally needed. If it still asks, check that you pasted the full address starting with https://github.com/, and if it persists send the message to a developer.

My deck or page needs a fine tweak+

Ask Claude in the same conversation. If you need manual editing, hand the HTML file to a developer: it is built with Tailwind for exactly that.

01Install with the CLI

Requires Claude Code. The plugin lives in the elaniin-style-marketplace marketplace of this repository.

bash 
# 1) add the marketplace
claude plugin marketplace add https://github.com/aidesign-elaniin/elaniin-style

# 2) install (user scope by default)
claude plugin install elaniin-style@elaniin-style-marketplace

# 3) verify
claude plugin list

Always use the same address (the full URL) in the app, the CLI and the settings. If you mix owner/repo with the URL, Claude Code rejects the marketplace with “network source differs”.

Inside a Claude Code session the same steps are:

claude code 
/plugin marketplace add https://github.com/aidesign-elaniin/elaniin-style
/plugin install elaniin-style@elaniin-style-marketplace
/reload-plugins

02Choose the scope

Add --scope to the install command. Local wins over project, and project wins over user.

user

~/.claude/settings.json

Default. For all your projects.

project

.claude/settings.json

Committed. Each collaborator runs install once.

local

.claude/settings.local.json

Only you, only this repo.

03Enable it in a shared repo

Commit this in .claude/settings.json so the whole team sees the marketplace. It applies after accepting the folder trust prompt, and each person still runs claude plugin install … --scope project once.

json 
{
  "extraKnownMarketplaces": {
    "elaniin-style-marketplace": {
      "source": { "source": "git", "url": "https://github.com/aidesign-elaniin/elaniin-style.git" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": {
    "elaniin-style@elaniin-style-marketplace": true
  }
}

04Repository access

The repository is public: no GitHub account, token or permissions are needed to install or update. If it ever becomes private, Claude Code will use the user's git credentials (gh auth login and gh auth setup-git over HTTPS, or an SSH key in ssh-agent).

05Update and uninstall

The plugin does not define version: every commit in the repo counts as a new version. With autoUpdate on it downloads by itself a few minutes after opening a session; the running session keeps the loaded version until /reload-plugins or a restart.

bash 
# update manually
claude plugin update elaniin-style@elaniin-style-marketplace
# or from a session
/plugin marketplace update elaniin-style-marketplace
/reload-plugins

# uninstall / remove the marketplace
claude plugin uninstall elaniin-style@elaniin-style-marketplace
claude plugin marketplace remove elaniin-style-marketplace

06Use the skill

Claude loads it on its own when the request fits. You can also invoke it by its namespaced name:

claude code 
/elaniin-style:elaniin-style

Four modes: deck, dashboard, website and site-dev (the Elaniin 2027 site in Next.js). Ask in Spanish or English; the skill answers in your language. The script that installs motion runs silently only if the project has a package.json.

07Edit a generated deck or page

Deliverables are a single self-contained HTML file: they carry Tailwind v4 (@tailwindcss/browser pinned to 4.3.3) and the token block embedded. They do not depend on the plugin staying installed and do not update on their own: they belong to the project. Edit them with Tailwind classes like any HTML.

Color

bg-elevate-blue · bg-excellence-blue · bg-inspire-grey · text-text-primary · text-text-secondary · text-text-muted

elevate-blue only as a detail (<5% of the area).

Typography

font-display · font-text · font-mono · text-display-xl · text-h1…h4 · text-lead · text-body · text-caption

Fluid scale; do not use loose sizes.

Shape and shadow

rounded-button · rounded-card · rounded-input · shadow-card-rest · shadow-menu · shadow-product

Radii and shadows come from @theme.

Layout

container-site · section-y · section-y-statement · section-y-compact · pad-card

Responsive gutter and vertical rhythm.

Motion

duration-fast · duration-base · duration-slow · duration-reveal · rise · reveal · card-glow · lift · btn-arrow

Named durations: never duration-200.

Focus

focus-ring · focus-ring-on-dark

Visible double ring on :focus-visible.

Hover cards

lift · card-glow + rounded-card border bg-surface-card pad-card

Always padded: never text touching the edge.

Grids

gap-grid · grid-page · grid-auto · grid-hairline

Section 11. No negative margins.

Mobile navigation

drawer · scrim + drawer.js

A 44px menu button that opens a real drawer.

Signature texture

module-field · module-field-dark · module-field-mask-left

Section 08. Hero and final CTA.

Breakpoints

sm 640 · md 768 · lg 1024 · xl 1280

Tailwind defaults are reset on purpose.

Rules when editing

  • No hex or loose values: use the token (bg-elevate-blue, not bg-[#1054ff]).
  • Tailwind's default colors and scales do not exist: bg-red-500 does not compile.
  • No loose class selectors in <style>: every new resource is a @utility.
  • The deck has no responsive classes: its canvas is always 1280×720. Use grid-cols-3, not md:grid-cols-3.
  • Keep min-w-0 on grid/flex children and overflow-hidden on cards: zero overflow.
  • Any element with lift or card-glow is a card: it gets rounded-card border bg-surface-card pad-card. Never text touching the hover edge, never negative margins.
  • Mobile navigation: if a nav is hidden below its breakpoint it needs a 44px menu button that opens a real drawer (drawer + scrim + drawer.js). A hamburger with no action is a bug; test at 375, 768 and 1280 px.
  • Respect reduced motion: every new animation must switch off with prefers-reduced-motion.

Example

html 
<a class="inline-flex h-12 items-center rounded-button bg-elevate-blue px-6
          font-display font-medium text-white hover:bg-blue-600 active:bg-blue-700
          transition-colors duration-base focus-ring">
  Get started
</a>

The browser script needs internet to compile. To move the piece into a real project, switch to the build plugin and paste tokens.css (it lives in skills/elaniin-style/templates/) into your entry CSS.

08Interactive texture: module field

It is the signature texture of the Elaniin site: a grid of 2 px squares every 16 px (grey at 45%) that, as the mouse moves, lights up cell by cell climbing the blue-300 → blue-400 → blue-500 ramp and fades out in ~260 ms. It goes in the background of the hero and the final CTA. It is the same one as on the elaniin-2027-website-main site, ported as a skill resource.

module-field

Resting grid, CSS only. First child of the host.

Required base.

module-field-dark

Faint white squares for dark bands.

On excellence-blue.

module-field-mask-left / -none

Fades to the left, or no fade.

By default it fades downward.

--module-size · --module-pitch

2px · 16px on :root. The trail reads them from CSS.

Change them only in tokens.

HTML (the host must have relative isolate overflow-hidden and the content relative):

html 
<section class="relative isolate overflow-hidden section-y">
  <div class="module-field" data-module-field aria-hidden="true"></div>
  <div class="container-site relative">…content…</div>
</section>

<!-- on a dark background, fading out to the left -->
<section class="relative isolate overflow-hidden section-y bg-excellence-blue text-white">
  <div class="module-field module-field-dark module-field-mask-left"
       data-module-field aria-hidden="true"></div>
  <div class="container-site relative">…content…</div>
</section>

The mouse trail is a ~90-line script with no dependencies. The templates already include it inline; in other projects:

html 
<script src="module-field.js"></script>
<!-- or paste the contents of templates/module-field.js inside a <script> at the end of body -->

React / Next.js

tsx 
// Next.js / React: copy templates/module-field.tsx to src/components/
import { ModuleField } from "@/components/module-field";

<section className="relative isolate overflow-hidden section-y">
  <ModuleField />                       {/* fade="bottom" tone="light" */}
  <div className="container-site relative">…</div>
</section>

<ModuleField fade="left" tone="dark" /> {/* for excellence-blue bands */}

Rules

  • Only in the hero and the final CTA, one per section. Never as card filler or behind long blocks of text.
  • It is texture, not the star: 45% resting opacity and no glows or gradients on top.
  • The squares are decorative: aria-hidden="true" and no pointer events of their own.
  • On touch screens and with prefers-reduced-motion there is no trail: only the static grid remains.
  • You also need the script if you add the texture to an already generated HTML: without it you only see the resting grid.

09Organization-wide rollout

To make auto-update mandatory so nobody can switch it off, put it in managed settings (Organization settings → Claude Code → Managed settings, MDM or managed-settings.json). With autoUpdate defined there, the /plugin toggle is locked.

json 
{
  "extraKnownMarketplaces": {
    "elaniin-style-marketplace": {
      "source": { "source": "git", "url": "https://github.com/aidesign-elaniin/elaniin-style.git" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": {
    "elaniin-style@elaniin-style-marketplace": true
  }
}

If you use DISABLE_AUTOUPDATER=1, add FORCE_AUTOUPDATE_PLUGINS=1 to keep plugin updates running.

10Troubleshooting

bash 
# Error "network source differs from the one declared in settings":
# the marketplace already existed with a different form of address. Remove it and add it again:
claude plugin marketplace remove elaniin-style-marketplace
claude plugin marketplace add https://github.com/aidesign-elaniin/elaniin-style

claude plugin list              # is it installed and enabled?
claude plugin details elaniin-style
/status                         # which settings apply?

Clone fails? Check your git credentials (block 04). Command missing? Run /reload-plugins or open a new session. Still on the old version? claude plugin update and reload.

11Grids

Tailwind already ships grid-cols-* and col-span-*. The plugin adds four utilities that connect them to the Elaniin tokens: always use them instead of building grids with loose values.

gap-grid

Token gap: 24px, 16px on mobile.

For any grid or flex.

grid-page

12 columns. Children with col-span-12 md:col-span-N.

Fixed count: KPIs, features, aside.

grid-auto

auto-fit with --card-min (16rem).

Unknown count: cards, logos.

grid-hairline

cells with 1px lines, no negative margins.

Stats and comparisons. With grid-cols-N and pad-card.

Rules

  • Mobile first: every child of grid-page gets col-span-12 and then scales up with md: or xl:.
  • min-w-0 on every grid or flex child with text, media or tables.
  • No negative margins (-mx-*) and no arbitrary gaps (gap-[18px]).
  • Do not use lift or card-glow inside grid-hairline: the clipping hides the shadow. For hover cards use grid-page or grid-auto.
  • The deck keeps explicit columns (grid-cols-3): its canvas is always 1280 px.
bash 
grep -n -E '\-mx-|gap-\[|grid-cols-\[' file.html            # must print nothing
