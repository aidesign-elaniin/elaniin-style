# Search keywords for references / Palabras clave de búsqueda

> Cuándo usarla: Fase 0, cuando el usuario no tiene referencias y hay que proponer
> direcciones o buscar inspiración. Combinar 1 keyword de categoría + 1–2 de estilo.

## Por plataforma

| Plataforma | Cómo buscar |
|---|---|
| **Dribbble** | `dribbble.com/search/<keywords>` o `dribbble.com/tags/<tag>` |
| **Behance** | `behance.net/search/projects/<query>?locale=en_US` o `?locale=es` |
| **Pinterest** | `pinterest.com` o `es.pinterest.com` — funciona bien en español |
| **Awwwards / Godly** | galerías curadas, buscar por tag |
| **Land-book / Lapa Ninja** | estructura de landing pages por categoría |
| **Siteinspire** | filtro por estilo/tema/plataforma |
| **Muzli** | colecciones curadas de landing pages y UI |
| **Mobbin** | flujos de producto reales (UX, no marketing) |

## Ejemplos de consulta combinada

- Landing SaaS limpia: `saas landing page` + `clean UI` / `light background`
- Dashboard fintech oscuro: `fintech dashboard` + `dark navy blue accent`
- Deck de inversión editorial: `startup pitch deck` + `editorial layout` / `swiss typography`
- Reporte ejecutivo: `reporting UI` + `data visualization` + `grid system`
- Landing bento: `bento grid landing` + `minimal tech`
